# Diagrams

Mermaid diagrams used in the FlexCheck hotel documentation.

## Files

- `context-architecture.mmd`: solution context view.
- `checkin-flow.mmd`: main check-in flow.

## How to View

Open the files in an IDE with Mermaid support or paste the content into a Mermaid renderer.

## Purpose

The diagrams support architecture presentation, user flow explanation, and component communication.
