# Diagramas

Diagramas Mermaid usados na documentacao do FlexCheck Hotel.

## Arquivos

- `arquitetura-contexto.mmd`: visao de contexto da solucao.
- `fluxo-checkin.mmd`: fluxo principal de check-in.

## Como Visualizar

Abra os arquivos em uma IDE com suporte a Mermaid ou cole o conteudo em um renderizador Mermaid.

## Uso

Os diagramas apoiam a apresentacao da arquitetura, fluxo do usuario e comunicacao entre componentes.
